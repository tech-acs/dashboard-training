# Folder Structure

The first thing you should do is familiarize yourself with the file and folder structure of the dashboard.

To begin, please read the [Directory Structure](https://laravel.com/docs/structure) section of the Laravel documentation.

While there are various directories that help organize your application, we will mainly be concerned with a few of them — the directories where your generated dashboard files (indicators, scorecards, gauges, etc.) will be stored.

## Key Directories

- **`app/Livewire`** — All your indicator, gauge, and scorecard files are stored here. You can organize them into thematic or data-source-based subdirectories by including folder paths in the names when using the various `make` commands (e.g., `KenyaCensus/PopulationDistribution`).

- **`app/Mail`** — Holds all Mailable classes which you can modify to affect the emails sent by the dashboard. The corresponding mail templates are stored in **`resources/views/mail`**.

- **`app/MapIndicators`** — Holds all `MapIndicator` classes generated by the `chimera:make-map-indicator` command.

- **`app/Reports`** — All your report class files are stored here. You can organize them into thematic or data-source-based subdirectories. The actual generated report files (CSV/Excel) are stored under the **`storage`** directory.

- **`config`** — Contains all configuration files that control various aspects of the dashboard. You rarely need to modify these files directly. Instead, use the **`.env`** file located in the project root directory to configure settings.

- **`resources/views`** — Holds all Blade templates for the dashboard application. You rarely need to modify these, but it is good to familiarize yourself with their organization.
