**Course Goal:** To empower developers, statisticians, and data scientists to build, customize, and deploy real-time monitoring dashboards for large-scale field data collection (Censuses and Surveys).

**Duration:** The course is expected to last 5-weeks, broken into 10 sessions (2 per week, 1 hour each).

### **Week 1: Fundamentals & Getting Started**
*Objectives: Provide some helpful foundation in git, PHP, web servers, CSPro, and databases. Get up and running with the training sandbox using docker and or WSL.*

* **Session 1: Fundamentals**
    * Understanding the basics of version control (Git and GitHub).
    * Understanding the basics of PHP
    * Understanding the basics of CSPro and questionnaire design.
    * Understanding the "Breakout" database structure.
  
* **Session 2: Getting Started**
    * Understanding the dual-database structure (Main App vs. Survey Data).
    * Using docker on Windows or WSL to run the project.
    * Running commands to initiate various actions in the dashboard.
    * Exploring included database client (Adminer) and Mailbox
    * Logging into the dashboard

### **Week 2: Foundation**
*Objectives: Understand the kit and basic configurations. Connect the dashboard to census data and understand how indicators are calculated.*

* **Session 1: Overview of the toolkit and basic configurations**
    * Architecture Overview
    * Understanding and configuration of data sources
    * Area hierarchies
    * Importing areas
* **Session 2: More configurations and dashboard artifacts**
    * Importing reference values
    * Summary cards, scorecards, indicators, and more.

### **Week 3: Building a Dashboard (part 1)**
*Objective: Connect your dashboard to census data and start seeing visualized data in the form of various types of artifacts.*

* **Session 1: CSPro data and how to query it**
    * Understanding CSPro data, dictionaries, and breakout databases.
    * Query Builder
    * Query Fragment Maker
    * Understanding the dashboard directory structure
* **Session 2: Making artifacts**
    * Making scorecards and indicators.
    * Understanding the Area Filter

### **Week 4: Building a Dashboard (part 2)**
*Objective: Making more artifact types and adding more functionality to the dashboard.*

* **Session 1: Making artifacts**
    * Making map indicators
    * Making gauges
* **Session 2: More artifacts**
    * Making reports.
    * Understanding Area Insights

### **Week 5: Advanced Topics**
*Objective: Getting really comfortable with the dashboard and implementing advanced functionality.*

* **Session 1: Localizing, understanding dev mode, and area restrictions**
    * Localizations
    * Understanding dev mode
    * Understanding area restrictions
* **Session 2: Caching, query analytics, and upgrading versions**
    * Caching
    * Query analytics 
    * Usage stats
    * Upgrading versions

### **Week 6: Dashboard Management**
*Objective: Effective management of dashboard for the best outcomes.*
* **Session 1: Users, roles, and settings**
    * Users, roles, and permissions
    * Settings
    * Announcements
* **Session 2: Exercises and wrap-up**
    * Attempting exercises
    * Wrap-up
